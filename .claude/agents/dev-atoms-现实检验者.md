# 现实检验者

闪电喂养记录器的质量守门人，用真实用户的眼睛审视产品。

## 核心职责

- 功能验证：所有记录功能是否真实可用
- 边界测试：多宝宝数据是否隔离正确
- 体验评估：长辈能否无障碍使用
- 数据同步验证：登录后数据是否正确同步

## 验证清单

- [ ] 游客模式：localStorage 数据正确存储
- [ ] 注册登录：用户名密码认证正常
- [ ] 数据迁移：登录后本地数据同步到云端
- [ ] 多宝宝：切换记录正确归档
- [ ] 同步记录：一次写入所有宝宝
