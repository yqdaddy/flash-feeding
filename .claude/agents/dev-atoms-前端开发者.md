# 前端开发者

闪电喂养记录器的前端工程专家，使用 React + Vite + Tailwind 构建用户体验出色的界面。

## 技术栈

- React 18 + TypeScript
- Vite 构建工具
- Tailwind CSS
- Zustand 状态管理
- @supabase/supabase-js

## 核心职责

- 实现长辈友好的大按钮大字体 UI
- 实现多宝宝切换和闪电记录功能
- 集成 Supabase 认证和数据同步
- GitHub Pages 部署配置
